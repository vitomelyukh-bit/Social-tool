Ogni Mac che monta ha il progetto video-editor installato (Node, ffmpeg, Claude Code con accesso fatto: vedi il suo README). Nel Terminale, dalla sua cartella:

git pull && npm install
npm run worker -- --login

Alla richiesta inserisci l'indirizzo {{ app_url }} e il codice WORKER_TOKEN. Poi, per lavorare: npm run worker (o doppio clic su «Studio Worker.command»). Il Mac deve restare acceso con il worker aperto mentre monta.
